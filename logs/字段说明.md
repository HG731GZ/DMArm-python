# 遥操作 CSV 字段说明

每个 `teleop_*.csv` 对应一次记录，每行对应一个采样点。默认采样间隔为 5 ms（200 Hz），相邻行的 `elapsed_s` 之差给出实际间隔。缺失值写为 `NULL`，从端某轴回报的无效净驱动力矩写为 `nan`。同目录的 `dataproc.m` 将两者都读为 MATLAB 的 `NaN`。

主端运行重力补偿并发布命令时，自动记录从最新有效从端帧的 `teleop_state` 非零的第一拍开始写入。该值回到 0 的当拍结束当前文件，再次开启跟随时另建文件。点击按钮开始的手动记录可以跨越跟随状态的切换，值回到 0 时继续采样。

## 时间与主端状态

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| `time_unix_s` | s | 主端记录本行时的 Unix 时间戳。 |
| `elapsed_s` | s | 按单调时钟计算的经过时间，本文件首行为 0。 |
| `master_can_cycle` | 轮 | 本次打开 CAN FD 设备以来，工作线程累计完成的控制周期数。 |
| `master_feedback_max_age_ms` | ms | 取六轴及夹钳各自最近的反馈，计算其中最早一条距本行采样时刻的时间。七个节点尚未全部收到过反馈时为 `NULL`。 |
| `master_force_feedback_on` | 0 / 1 | 主端关节阻抗力反馈的开关状态，1 为开启，0 为关闭。 |

## 六轴关节量

下表的 `{n}` 取 1～6。`dataproc.m` 将每组六个字段按 J1～J6 合并成一个 `N×6` 数组，`N` 为采样行数。例如 `master_q_rad(:,3)` 和 `slave_q_rad(:,3)` 分别是主端、从端 J3 的关节角。其余字段按 CSV 原名导入为 `N×1` 列向量。

| CSV 字段 | MATLAB 数组 | 单位 | 含义 |
| --- | --- | --- | --- |
| `master_j{n}_q_rad` | `master_q_rad` | rad | 从电机反馈换算的主端 DH 关节角，范围为 (−π, π]。J3 的电机与关节正向相反。 |
| `master_j{n}_dq_rad_s` | `master_dq_rad_s` | rad/s | 主端实测关节角速度，正方向与 DH 关节角一致。 |
| `master_j{n}_filtered_velocity_error_rad_s` | `master_filtered_velocity_error_rad_s` | rad/s | DH 关节系中从端减主端的滤波速度差。开启力反馈时，控制器将它乘以该轴阻尼系数，得到限幅前的阻尼力矩分量。 |
| `master_j{n}_motor_position_rad` | `master_motor_position_rad` | rad | 主端电机在自身坐标系下反馈的位置。 |
| `master_j{n}_motor_velocity_rad_s` | `master_motor_velocity_rad_s` | rad/s | 主端电机反馈的角速度。 |
| `master_j{n}_motor_torque_nm` | `master_motor_torque_nm` | N·m | 主端电机反馈的力矩。 |
| `master_j{n}_motor_status` | `master_motor_status` | 状态码 | 主端电机反馈的驱动状态，码值见“主端夹钳反馈”一节。 |
| `master_j{n}_mit_command_nm` | `master_mit_command_nm` | N·m | 该轴在 MIT 模式下最近的电机侧力矩指令。 |
| `master_j{n}_pv_command_rad` | `master_pv_command_rad` | rad | 该轴在 PV 模式下最近的电机侧目标位置。 |
| `slave_j{n}_q_rad` | `slave_q_rad` | rad | 从端 UDP 帧回传的关节角。 |
| `slave_j{n}_dq_rad_s` | `slave_dq_rad_s` | rad/s | 从端回传的实际关节角速度。 |
| `slave_j{n}_net_torque_nm` | `slave_net_torque_nm` | N·m | 从端回传的关节净驱动力矩，有效性按轴判断。 |

主端本拍发布命令时，DH 角度和速度取自实际发出的报文。仅手动采样时，按已有的电机反馈逐轴换算。MIT 和 PV 指令按各轴当时的模式填写，未适用或尚无指令的列为 `NULL`。

主端六轴和从端速度反馈都有效时，CAN 工作线程持续计算速度差。只听和失能姿态读取也使用已有回包。开关力反馈时滤波连续，日志开启后按 200 Hz 节拍读取最近快照，所以 `master_force_feedback_on = 0` 的采样行也可以有这六个数值。

首次配对及断流恢复后的首拍采用实测速度差，后续按六轴 CAN 样本的实际时间间隔更新一阶低通滤波器。时间常数由 `main.py` 的 `FORCE_FEEDBACK_VELOCITY_FILTER_S` 设置，设为 0 时直通。任一端反馈缺失或过期时，这六列记为 `NULL`，MATLAB 读为 `NaN`。

## 主端夹钳反馈

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| `master_gripper_motor_position_rad` | rad | 夹钳电机反馈的位置。 |
| `master_gripper_motor_velocity_rad_s` | rad/s | 夹钳电机反馈的角速度。 |
| `master_gripper_motor_torque_nm` | N·m | 夹钳电机反馈的力矩。 |
| `master_gripper_motor_status` | 状态码 | 夹钳电机反馈的驱动状态，与六轴共用码值。 |
| `master_gripper_force_n` | N | 取夹钳电机反馈力矩的相反数，除以 0.01 m 估算夹持力，负值按 0 N 记录。 |

六轴与夹钳的驱动状态码均为十进制。0 为失能，1 为使能，8 为超压，9 为欠压，10 为过流，11 为 MOS 过热，12 为线圈过热，13 为通讯丢失，14 为过载。

## UDP 命令与从端帧

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| `master_udp_mode` | 协议码 | 主端命令帧的模式字节，当前发送值为 1。 |
| `master_udp_grip_1` | 协议值 | 主端命令帧的第一个夹钳字段，取夹钳电机位置（rad）的数值并限制在 [0, 0.99]。 |
| `master_udp_grip_2`、`master_udp_grip_3` | 协议值 | 主端命令帧的第二、第三个夹钳字段，当前均发送 0。 |
| `slave_received_unix_s` | s | 主端收到本行所用从端帧时的 Unix 时间戳。同一有效帧可用于连续多个采样点。 |
| `slave_generation` | 段 | 本次 UDP 连接的连续接收段编号，首段为 1。相邻有效帧间隔超过 `UDP_TIMEOUT_S` 时，下一帧开始新的一段。 |
| `slave_mode` | 协议码 | 从端反馈帧中的模式字节，按收到的数值记录。 |
| `slave_grip_1`、`slave_grip_2`、`slave_grip_3` | 从端定义 | 从端反馈帧中按协议顺序排列的三个夹钳值，主端原样记录。 |

本拍没有发布主端命令时，`master_udp_*` 为 `NULL`。手动记录尚未收到有效从端帧时，所有 `slave_*` 为 `NULL`，可用 `~isnan(slave_received_unix_s)` 在 MATLAB 中选出有从端帧的采样行。记录中已收到有效帧后，从端断流会结束当前文件。
