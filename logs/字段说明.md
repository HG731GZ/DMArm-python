# 遥操作 CSV 字段说明

每个 `teleop_*.csv` 对应一次记录，每行对应一个采样点。默认采样间隔为 5 ms（200 Hz），相邻行的 `elapsed_s` 之差给出实际间隔。未取得的采样字段写为 `NULL`；有效从端帧中的夹爪、力矩和加速度空值原样写为 `nan`，不补零，也不沿用旧值。同目录的 `dataproc.m` 将两者都读为 MATLAB 的 `NaN`。

当前 UDP v2 使用 159 字节命令和 336 字节反馈。此前 2026-11-24 版使用 133/230 字节，引入了 `slave_teleop_state` 和六轴 `slave_j{n}_ddq_rad_s2`，原 `slave_j{n}_net_torque_nm` 改名为 `slave_j{n}_torque_nm`，原 `slave_grip_1/2/3` 分别改名为 `slave_gripper_open`、`slave_gripper_current_raw`、`slave_gripper_position_raw`。旧 CSV 仍按原表头导入。

主端运行重力补偿并发布命令时，自动记录从最新有效从端帧的 `teleop_state` 非零的第一拍开始写入。该值回到 0 的当拍结束当前文件，再次开启跟随时另建文件。点击按钮开始的手动记录可以跨越跟随状态的切换，值回到 0 时继续采样。

## 时间与主端状态

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| `time_unix_s` | s | 主端记录本行时的 Unix 时间戳。 |
| `elapsed_s` | s | 按单调时钟计算的经过时间，本文件首行为 0。 |
| `master_can_cycle` | 轮 | 本次打开 CAN FD 设备以来，收发进程已确认整批回包的累计轮数，同一有效指令重复发送并收齐也计一轮。 |
| `master_feedback_max_age_ms` | ms | 取六轴及夹钳各自最近的反馈，计算其中最早一条距本行采样时刻的时间。七个节点尚未全部收到过反馈时为 `NULL`。 |
| `master_force_feedback_on` | 0 / 1 | 主端关节阻抗力反馈的开关状态，1 为开启，0 为关闭。 |

## 六轴关节量

下表的 `{n}` 取 1～6。`dataproc.m` 将每组六个字段按 J1～J6 合并成一个 `N×6` 数组，`N` 为采样行数。例如 `master_q_rad(:,3)` 和 `slave_q_rad(:,3)` 分别是主端、从端 J3 的关节角。其余字段按 CSV 原名导入为 `N×1` 列向量。

| CSV 字段 | MATLAB 数组 | 单位 | 含义 |
| --- | --- | --- | --- |
| `master_j{n}_q_rad` | `master_q_rad` | rad | 从电机反馈换算的主端 DH 关节角，范围为 (−π, π]。J3 的电机与关节正向相反。 |
| `master_j{n}_dq_rad_s` | `master_dq_rad_s` | rad/s | 主端实测关节角速度，正方向与 DH 关节角一致。 |
| `master_j{n}_filtered_velocity_error_rad_s` | `master_filtered_velocity_error_rad_s` | rad/s | DH 关节系中从端减主端的滤波速度差，仅用于观测，不再参与力反馈输出。 |
| `master_j{n}_local_damping_nm` | `master_local_damping_nm` | N·m | 本拍 CAN 主端实测关节速度乘以负的本地阻尼系数，未经反馈合成限幅。与预测权重无关，力反馈按钮关闭时也持续观测。 |
| `master_j{n}_motor_position_rad` | `master_motor_position_rad` | rad | 主端电机在自身坐标系下反馈的位置。 |
| `master_j{n}_motor_velocity_rad_s` | `master_motor_velocity_rad_s` | rad/s | 主端电机反馈的角速度。 |
| `master_j{n}_motor_torque_nm` | `master_motor_torque_nm` | N·m | 主端电机反馈的力矩。 |
| `master_j{n}_motor_status` | `master_motor_status` | 状态码 | 主端电机反馈的驱动状态，码值见“主端夹钳反馈”一节。 |
| `master_j{n}_mit_command_nm` | `master_mit_command_nm` | N·m | 该轴在 MIT 模式下最近的电机侧力矩指令。 |
| `master_j{n}_pv_command_rad` | `master_pv_command_rad` | rad | 该轴在 PV 模式下最近的电机侧目标位置。 |
| `slave_j{n}_q_rad` | `slave_q_rad` | rad | 从端 UDP 帧回传的关节角。 |
| `slave_j{n}_dq_rad_s` | `slave_dq_rad_s` | rad/s | 从端回传的实际关节角速度。 |
| `slave_j{n}_torque_nm` | `slave_torque_nm` | N·m | 阻抗控制时为送入 `direct_torque()` 的限幅、限变化率后的命令力矩；普通控制及关节力矩输入的导纳为补偿实测力矩。无有效样本时为 `nan`。 |
| `slave_j{n}_ddq_rad_s2` | `slave_ddq_rad_s2` | rad/s² | 从端实际关节角加速度，直接记录，不再除以 10⁶。无有效阻抗样本时为 `nan`，零是有效值。 |

力矩来源没有独立的协议标记，需要结合已知业务模式解释，不能仅凭 `slave_mode` 或 `slave_teleop_state` 推断。加速度可用性只按字段的 `NaN` 判断；轨迹、阶跃阻抗的 `slave_teleop_state` 可以为 0 且加速度有效。当前发送端按夹爪三个值、力矩六轴、加速度六轴分别成组置空，一组空值不影响其他组的记录。

主端本拍发布命令时，DH 角度和速度取自实际发出的报文。仅手动采样时，按已有的电机反馈逐轴换算。MIT 和 PV 指令按各轴当时的模式填写，未适用或尚无指令的列为 `NULL`。

主端六轴和从端速度反馈都有效时，控制线程按实际采用的完整 CAN 样本计算速度差。只听和失能姿态读取也使用已有回包。开关力反馈时滤波连续，独立的 UDP 发布线程按 200 Hz 节拍采样，所以 `master_force_feedback_on = 0` 的采样行也可以有这六个数值。主端位置、速度和已下发指令取最近确认的硬件批次，阻尼、预测及候选力矩对应最近一次控制计算，两者可以相差若干 CAN 轮。

首次配对及断流恢复后的首拍采用实测速度差，后续按六轴 CAN 样本的实际时间间隔更新一阶低通滤波器。时间常数由 `main.py` 的 `FORCE_FEEDBACK_VELOCITY_FILTER_S` 设置，设为 0 时直通。任一端反馈缺失或过期时，这六列记为 `NULL`，MATLAB 读为 `NaN`。

本地阻尼直接使用本拍主端实测速度，不使用上述低通滤波结果，也不使用从端速度或预测速度。`FORCE_FEEDBACK_DAMPING_NM_S_PER_RAD` 是 J1～J6 的本地阻尼系数。反馈缺失或过期时，本地阻尼观测列也记为 `NULL`。

## 自由空间预测补偿

`main.py` 的 `FORCE_FEEDBACK_PREDICTION_ENABLED` 控制是否启用预测。启用后，主端持续发布、从端有效跟随时，即使力反馈按钮关闭，也持续计算预测与反馈候选值。取消主端发布、从端退出跟随、断流或连接更换时结束预测会话；重新进入会话时，用首个有效从端状态初始化一次。力反馈按钮本身不重置预测轨迹。

`FORCE_FEEDBACK_PREDICTION_WEIGHT` 按 J1～J6 设置位置补偿权重 α，每项取 0～1。令 `e0 = wrap(q_slave − q_master)`、`ep = wrap(q_slave − q_predicted)`。每轴先计算原始弹簧 `s0 = K × e0` 和加权弹簧 `sα = K × ((1 − α) × e0 + α × ep)`，再取 `s = clip(sα, min(0, s0), max(0, s0))`。这样预测可以将回拉力矩减到零，同向时最多保留原始弹簧力矩。最后叠加本地阻尼并按关节侧上限输出 `clip(s − B × dq_master, ±limit)`。预测关闭或 α 为 0 时使用原始弹簧，α 为 1 时将完整预测弹簧代入同一约束。

预测器仅使用实际成功发出的主端位置指令，以及 `FREE_SPACE_*` 配置中的速度上限、正负向起步加速度、制动减速度和滞后。在线运行不读取从端加速度或力矩。内部按固定步长积分，在每个从端回包的单调接收时刻取预测位置和速度；重复使用同一回包时，预测参考也保持在该回包时刻。

| CSV 字段 | 单位 | 含义 |
| --- | --- | --- |
| `master_prediction_enabled` | 0 / 1 | 本次主端配置是否启用预测补偿，与力反馈按钮开关独立。 |
| `master_prediction_ready` | 0 / 1 | 本次 CAN 快照是否有已初始化的预测与反馈候选值。 |
| `master_prediction_observation_age_ms` | ms | 本行记录时刻距离预测残差所用 CAN 样本时刻的时间。 |
| `master_prediction_slave_received_unix_s` | s | 预测残差实际配对的从端帧接收时间。它可能早于本行 `slave_received_unix_s`，因为日志线程读取的从端最新帧与 CAN 快照异步更新。 |
| `master_j{n}_prediction_weight` | 无量纲 | 当前配置的该轴位置补偿权重 α。预测关闭时仍记录配置值，但输出等效使用 α 为 0。 |
| `master_j{n}_predicted_slave_q_rad` | rad | 在上述从端帧接收时刻的自由空间预测角度，以最短角度范围记录。 |
| `master_j{n}_predicted_slave_dq_rad_s` | rad/s | 同一时刻的预测速度。 |
| `master_j{n}_prediction_position_error_rad` | rad | 控制器实际使用的最短位置残差：配对帧的从端角度减预测角度。 |
| `master_j{n}_prediction_filtered_velocity_error_rad_s` | rad/s | 配对帧从端速度减预测速度，按 CAN 样本间隔进行一阶低通后的残差，仅用于观测。 |
| `master_j{n}_original_feedback_nm` | N·m | 同一 CAN 观测下，原始主从位置差加本地阻尼的关节侧反馈候选值，对应 α 为 0，已做反馈合成限幅。 |
| `master_j{n}_predicted_feedback_nm` | N·m | 完整预测弹簧加本地阻尼的对照值，已做关节侧总限幅。此列保留施加弹簧方向与幅值约束前的定义。 |
| `master_j{n}_weighted_feedback_nm` | N·m | 按当前权重对弹簧施加方向与幅值约束，叠加本地阻尼并做关节侧总限幅。启用预测且力反馈开启时，控制器使用此值。 |
| `master_j{n}_unconstrained_weighted_feedback_nm` | N·m | 同一拍、同一权重下跳过弹簧约束的反馈对照值。与上一列使用相同的本地阻尼和关节侧总限幅。旧日志缺少此列时，`weighted_feedback_nm` 记录当时未施加弹簧约束的加权反馈。 |

上述反馈值均为关节侧力矩，与 `master_force_feedback_on` 独立。开启力反馈后，控制器按传动方向换算力矩，叠加电机侧重力补偿，再施加电机总力矩上限。未启用预测或预测会话未就绪时，预测状态、残差及四组反馈值均记为 `NULL`，配置权重和有效的本地阻尼观测仍正常记录。两组滤波速度差仅用于观测。

2026-11-24 改成本地阻尼后，新日志含 `local_damping_nm`、`prediction_weight` 和 `weighted_feedback_nm` 三组六轴列。没有这些列的旧日志仍按当时的控制律解释：原始候选值用主从速度差，预测候选值用从端减预测速度差；旧文件不改写。

## 主端夹钳反馈

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| `master_gripper_motor_position_rad` | rad | 夹钳电机反馈的位置。 |
| `master_gripper_motor_velocity_rad_s` | rad/s | 夹钳电机反馈的角速度。 |
| `master_gripper_motor_torque_nm` | N·m | 夹钳电机反馈的力矩。 |
| `master_gripper_motor_status` | 状态码 | 夹钳电机反馈的驱动状态，与六轴共用码值。 |
| `master_gripper_force_n` | N | 取夹钳电机反馈力矩的相反数，除以 0.01 m 估算夹持力，负值按 0 N 记录。 |

六轴与夹钳的驱动状态码均为十进制。0 为失能，1 为使能，8 为超压，9 为欠压，10 为过流，11 为 MOS 过热，12 为线圈过热，13 为通讯丢失，14 为过载。

## UDP 命令与从端帧

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| `master_udp_mode` | 协议码 | 主端命令帧的模式字节，当前发送值为 1。 |
| `master_udp_grip_1` | 协议值 | 主端命令帧的第一个夹钳字段，取夹钳电机位置（rad）的数值并限制在 [0, 0.99]。 |
| `master_udp_grip_2`、`master_udp_grip_3` | 协议值 | 主端命令帧的第二、第三个夹钳字段，当前均发送 0。 |
| `slave_received_unix_s` | s | 主端收到本行所用从端帧时的 Unix 时间戳。同一有效帧可用于连续多个采样点。 |
| `slave_generation` | 段 | 本次 UDP 连接的连续接收段编号，首段为 1。有效新帧间隔超过 `UDP_TIMEOUT_S` 或从端发布会话切换时开始新段。 |
| `slave_mode` | 协议码 | 原样记录，当前固定为 0，不能表示实际控制模式或反馈有效性。 |
| `slave_teleop_state` | 状态码 | 0：无有效遥操作（也包含同步、准备、停止及非遥操作阻抗）；1：普通 RTDE 跟随；2：遥操作阻抗。不是完整运动或安全状态。 |
| `slave_gripper_open` | 无量纲 | 夹爪开度 0～1，1 为最大开口，0 为闭合；不可用时为 `nan`。 |
| `slave_gripper_current_raw` | 原始寄存器值 | 电流/力矩寄存器原始数值，未换算为 A、mA 或 N·m；不可用时为 `nan`。 |
| `slave_gripper_position_raw` | 原始计数 | 夹爪原始位置计数，不是 mm；当前 0 为最大开口、9000 为闭合，开度为 `(9000 - position_raw) / 9000`；不可用时为 `nan`。 |

本拍没有发布主端命令时，`master_udp_*` 为 `NULL`。手动记录尚未收到有效从端帧时，所有 `slave_*` 为 `NULL`，可用 `~isnan(slave_received_unix_s)` 在 MATLAB 中选出有从端帧的采样行。记录中已收到有效帧后，从端断流会结束当前文件。

v2 新列依次为 `slave_session, fb_seq, echo_master_session, echo_cmd_seq, echo_t1_us, t2_us, t3_us, applied_master_session, applied_cmd_seq, t_apply_us, t_qdq_us, t_tau_us, t_ddq_us, t4_us`。这些字段和本行六轴从端值来自同一帧。字段末尾的 `_us` 表示整数微秒，会话和序号为无符号整数。整帧缺失写 `NULL`，帧内尚无事件的字段沿用协议值 0。MATLAB 导入时这些列使用 `uint64`，缺失填 0，可通过 `slave_received_unix_s` 判断该行是否有帧。

相邻行可能重复采用同一帧，也可能跨过数个反馈序号。角度与速度同源，力矩和加速度各取对应缓存的更新时间。夹爪没有独立源时刻。轨迹、阶跃阻抗仍使用手动记录。逐包统计、字段的时钟归属和静止采集步骤见[主端 UDP 网络测时](../主端UDP网络测时.md)。
